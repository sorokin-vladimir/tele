# Клавиши

> Перевод [keybindings.md](../keybindings.md) на коммит `a8ea9ea`. Если перевод расходится с английской версией, верна английская.

<a id="global"></a>
## Везде

| Клавиша                   | Действие        |
| ------------------------- | --------------- |
| `0`                       | Перейти к папкам |
| `1` / `h` / `←`           | Перейти к списку чатов |
| `2` / `l` / `→`           | Перейти к чату  |
| `q` / `Ctrl+Q` / `Ctrl+C` | Выйти           |
| `?`                       | Клавиатурные сокращения |
| `,`                       | Настройки       |
| `g L`                     | Выйти из аккаунта |

`g L` сначала спрашивает и перечисляет, что уйдёт вместе с аккаунтом: сессия, локальная история, кэш медиа и аватаров и сообщения, которые ещё ждут отправки.

На экране входа выходят из программы только `Ctrl+Q` и `Ctrl+C`, на любом шаге, в том числе пока tele ещё подключается.
Простая `q` вводится в поле.
Выход, который вы переназначили, работает там, только если в нём есть `ctrl` или `alt`.

<a id="forum-topics"></a>
## Темы форума

Пока список тем форума открыт, он занимает панель списка чатов.
По темам перемещаются клавишами списка чатов.

| Клавиша   | Действие                                 |
| --------- | ---------------------------------------- |
| `Enter`   | Открыть тему                             |
| `Space`   | Меню темы: отметить прочитанной, выключить / включить уведомления |
| `Esc`     | Назад к списку чатов                     |

<a id="chat-normal-mode"></a>
## Чат (обычный режим)

| Клавиша   | Действие                       |
| --------- | ------------------------------ |
| `j`       | Выбрать следующее (более новое) сообщение |
| `k`       | Выбрать предыдущее (более старое) сообщение |
| `Ctrl+J` / `↓` | Прокрутить вниз           |
| `Ctrl+K` / `↑` | Прокрутить вверх          |
| `gg`      | В самый верх                   |
| `G`       | В самый низ                    |
| `i` / `a` | Написать сообщение (режим ввода) |
| `r`       | Ответить на сообщение          |
| `t`       | Поставить реакцию              |
| `e`       | Изменить своё сообщение        |
| `d`       | Удалить своё сообщение         |
| `f`       | Переслать сообщение в другой чат |
| `u`       | Прикрепить файл для отправки   |
| `x`       | Отменить подготовленную загрузку / снять ответ или правку |
| `s`       | Скачать выбранный файл         |
| `g`       | Перейти к исходному сообщению (для ответов) |
| `o`       | Открыть / посмотреть медиа: фото в просмотрщике ОС, видео прямо в чате (Kitty + ffmpeg) или в системном плеере |
| `O`       | Открыть выбранное видео во внешнем плеере |
| `p`       | Воспроизвести голосовое (в приложении) |
| `P`       | Профиль автора выбранного сообщения или собеседника в личном чате |
| `Space`   | Контекстное меню               |
| `Enter`   | Повторить неудачную отправку (если такое сообщение выбрано) |

Сообщение, которое не удалось отправить, остаётся в чате с отметкой `✕` на нижней рамке; если его выбрать, в строке состояния будет названа причина.
`Enter` ставит его в очередь снова, а `Space` открывает короткое меню с вариантами Retry и Discard.
На `x` это не влияет: она по-прежнему снимает подготовленный ответ, правку или загрузку и никогда не трогает сообщение в очереди.

<a id="profile-overlay-p-or-profile-in-either-context-menu"></a>
## Окно профиля (`P` или `Profile` в любом из контекстных меню)

| Клавиша | Действие                                    |
| ------- | ------------------------------------------- |
| `j`/`k` | Перемещаться между действиями               |
| `o`     | Открыть чат с этим человеком                |
| `m`     | Выключить / включить уведомления (только если чат есть) |
| `y`     | Скопировать username                        |
| `Esc`   | Закрыть                                     |

Окно открывается с тем, что известно сразу, и дополняется, когда ответит Telegram.
Для человека, которому вы никогда не писали, пункта про уведомления нет: выключать уведомления не у чего, а угаданное состояние было бы хуже, чем никакое.

<a id="customizing-keybindings"></a>
## Как переназначить клавиши

Клавиши по умолчанию переопределяются в разделе `keybindings:` файла `~/.config/tele/config.yml`.
В сгенерированном конфиге уже перечислены **все действия с их текущими клавишами по умолчанию**, закомментированные: достаточно раскомментировать строку и поменять клавиши.
Привязки сгруппированы сначала по **контексту**, затем по **действию**:

```yaml
keybindings:
  chat:
    reply: "R" # a single key
    go_top: ["g g", "gg"] # several keys for one action
  chatlist:
    confirm: "l"
```

- **Замена, а не добавление:** перечисленные клавиши становятся _единственными_ клавишами этого действия в этом контексте.
  Действия, которые вы не упомянули, сохраняют клавиши по умолчанию.
- **Аккорды:** последовательность из нескольких клавиш записывается через пробел: `"g g"` значит нажать `g`, затем `g`.
  Клавиши называются так, как их называет терминал (`ctrl+d`, `enter`, `esc`, `space`, `up`, ...).
- **Конфликты** (неизвестное действие или контекст, пустая клавиша, клавиша, занятая двумя действиями, или одиночная клавиша, которая перекрывает аккорд) записываются в лог как предупреждения при запуске и пропускаются или применяются по принципу «побеждает последняя»; неправильный раздел никогда не роняет приложение.

**Контексты:** `global`, `folders`, `chatlist`, `chat`, `composer`, `search`, `context_menu`, `delete_submenu`, `chat_menu`, `folder_submenu`, `filepicker`.

<a id="configurable-actions"></a>
## Настраиваемые действия

Это имена действий, которые можно использовать как ключи YAML в разделе `keybindings:` (сгруппированы по `context`).

<a id="focus--app---context-global"></a>
### Фокус и приложение, контекст `global`

| Действие        | Описание                   |
| --------------- | -------------------------- |
| `focus_folders` | Перейти к боковой панели папок |
| `focus_chatlist`| Перейти к списку чатов     |
| `focus_chat`    | Перейти к панели чата      |
| `focus_prev`    | Перейти к предыдущей панели |
| `focus_next`    | Перейти к следующей панели |
| `quit`          | Выйти из приложения        |
| `log_out`       | Выйти из этого аккаунта    |

> Если включён `ui.confirm_quit`, любая привязка выхода сначала спрашивает: `y` или `enter` выходят, `n`, `esc` или `q` отменяют, а повторное нажатие привязки выхода с модификатором (`ctrl+c`, `ctrl+q`) выходит без вопроса.

<a id="navigation--scrolling---contexts-folders-chatlist-chat-context_menu-delete_submenu-search"></a>
### Навигация и прокрутка, контексты `folders`, `chatlist`, `chat`, `context_menu`, `delete_submenu`, `search`

| Действие           | Описание                             |
| ------------------ | ------------------------------------ |
| `up`               | Переместить выделение вверх / прокрутить вверх |
| `down`             | Переместить выделение вниз / прокрутить вниз |
| `go_top`           | В самый верх (первое / самое старое) |
| `go_bottom`        | В самый низ (последнее / самое новое) |
| `scroll_half_down` | Прокрутить на полстраницы вниз       |
| `scroll_half_up`   | Прокрутить на полстраницы вверх      |
| `cursor_down`      | Перевести курсор сообщения на следующий (более новый) пузырь |
| `cursor_up`        | Перевести курсор сообщения на предыдущий (более старый) пузырь |
| `confirm`          | Подтвердить / открыть выбранное      |

<a id="file-picker---context-filepicker"></a>
### Выбор файла, контекст `filepicker`

| Действие  | Описание                          |
| --------- | --------------------------------- |
| `up`      | Переместить выделение вверх       |
| `down`    | Переместить выделение вниз        |
| `confirm` | Выбрать подсвеченный файл         |
| `cancel`  | Закрыть выбор файла               |

> Клавиши записываются так, как их называет терминал: буквы и цифры как есть (`r`, `G`, `2`), модификаторы вида `ctrl+d` и именованные клавиши `enter`, `esc`, `space`, `up`, `down`, `left`, `right`.

> **Раскладка клавиатуры:** привязки к буквам срабатывают и на **той же физической клавише** в русской раскладке (ЙЦУКЕН): `r`/Reply работает, печатает ли клавиша `r` или `к`.
> Привязки всё равно пишутся латиницей, дублировать их не нужно.
> (Пока поддерживается только русская раскладка.)
