> 本文译自 [keybindings.md](../keybindings.md)，对应提交 `a8ea9ea`。译文与英文版不一致时，以英文版为准。本译文尚未经过母语者审校。如果发现翻译错误，欢迎[提交 issue](https://github.com/sorokin-vladimir/tele/issues)。

<a id="global"></a>
## 全局

| 按键                      | 操作            |
| ------------------------- | --------------- |
| `0`                       | 聚焦文件夹      |
| `1` / `h` / `←`           | 聚焦聊天列表    |
| `2` / `l` / `→`           | 聚焦聊天        |
| `q` / `Ctrl+Q` / `Ctrl+C` | 退出            |
| `?`                       | 快捷键一览      |
| `,`                       | 设置            |
| `g L`                     | 退出登录        |

`g L` 会先询问，并列出会随账号一起删除的内容：会话、本地历史、缓存的媒体和头像，以及仍在等待发送的消息。

在登录界面，任何一步都只有 `Ctrl+Q` 和 `Ctrl+C` 能退出，包括 tele 仍在连接时。单独的 `q` 会被输入到输入框中。你重新绑定的退出键只有包含 `ctrl` 或 `alt` 时才在那里生效。

<a id="forum-topics"></a>
## 论坛话题

论坛的话题列表打开时会占据聊天列表面板。用聊天列表的按键在话题间移动。

| 按键      | 操作                                     |
| --------- | ---------------------------------------- |
| `Enter`   | 打开话题                                 |
| `Space`   | 话题菜单：标记为已读、静音 / 取消静音    |
| `Esc`     | 返回聊天列表                             |

## 聊天（普通模式）

| 按键      | 操作                           |
| --------- | ------------------------------ |
| `j`       | 选择下一条（较新的）消息       |
| `k`       | 选择上一条（较旧的）消息       |
| `Ctrl+J` / `↓` | 向下滚动                  |
| `Ctrl+K` / `↑` | 向上滚动                  |
| `gg`      | 滚动到顶部                     |
| `G`       | 滚动到底部                     |
| `i` / `a` | 撰写消息（插入模式）           |
| `r`       | 回复消息                       |
| `t`       | 对消息做出反应                 |
| `e`       | 编辑自己的消息                 |
| `d`       | 删除自己的消息                 |
| `f`       | 将消息转发到其他聊天           |
| `u`       | 附加要发送的文件               |
| `x`       | 取消待发送的上传 / 清除回复或编辑 |
| `s`       | 下载选中的文件                 |
| `g`       | 跳转到原消息（用于回复）       |
| `o`       | 打开 / 查看媒体：图片在系统查看器中打开，视频在聊天中播放（Kitty + ffmpeg）或在系统播放器中播放 |
| `O`       | 在外部播放器中打开选中的视频   |
| `p`       | 播放语音消息（应用内）         |
| `P`       | 选中消息作者的资料，或私聊对方的资料 |
| `Space`   | 上下文菜单                     |
| `Enter`   | 重新发送失败的消息（选中时）   |

无法发送的消息会留在聊天中，在其底部边框上标有 `✕`；选中它时，状态栏会显示原因。`Enter` 把它重新放入队列，`Space` 打开一个提供 Retry 和 Discard 的小菜单。`x` 不受影响：它仍然只清除待发送的回复、编辑或上传，从不触及队列中的消息。

<a id="profile-overlay-p-or-profile-in-either-context-menu"></a>
## 资料面板（`P`，或任一上下文菜单中的 `Profile`）

| 按键    | 操作                                        |
| ------- | ------------------------------------------- |
| `j`/`k` | 在操作之间移动                              |
| `o`     | 打开与此人的聊天                            |
| `m`     | 静音 / 取消静音（仅在已有聊天时）           |
| `y`     | 复制用户名                                  |
| `Esc`   | 关闭                                        |

面板会先显示已知的信息，等 Telegram 回应后再补全其余内容。对于你从未发过消息的人，没有静音选项：没有可以静音的聊天，而猜测的状态比没有状态更糟。

<a id="customizing-keybindings"></a>
## 自定义快捷键

在 `~/.config/tele/config.yml` 的 `keybindings:` 一节中覆盖默认按键。生成的配置中已经以注释形式列出了**每个操作及其当前默认按键**：取消注释一行并修改按键即可。绑定先按**上下文**分组，再按**操作**分组：

```yaml
keybindings:
  chat:
    reply: "R" # a single key
    go_top: ["g g", "gg"] # several keys for one action
  chatlist:
    confirm: "l"
```

- **替换，而非追加：** 你列出的按键会成为该上下文中该操作的*唯一*按键。没有提到的操作保留默认按键。
- **组合键序列：** 多键序列用空格分隔的按键名表示：`"g g"` 表示先按 `g` 再按 `g`。按键名使用终端的叫法（`ctrl+d`、`enter`、`esc`、`space`、`up`……）。
- **冲突**（未知的操作或上下文、空按键、一个按键用于两个操作，或者单个按键遮挡了组合键序列）会在启动时作为警告记入日志，并被跳过或按“最后一个生效”处理；有问题的配置节永远不会让应用崩溃。

**上下文：** `global`、`folders`、`chatlist`、`chat`、`composer`、`search`、`context_menu`、`delete_submenu`、`chat_menu`、`folder_submenu`、`filepicker`。

<a id="configurable-actions"></a>
## 可配置的操作

以下是可以在 `keybindings:` 一节中用作 YAML 键的操作名（按 `context` 分组）。

<a id="focus--app---context-global"></a>
### 焦点与应用，上下文 `global`

| 操作            | 说明                       |
| --------------- | -------------------------- |
| `focus_folders` | 聚焦文件夹侧栏             |
| `focus_chatlist`| 聚焦聊天列表               |
| `focus_chat`    | 聚焦聊天面板               |
| `focus_prev`    | 聚焦上一个面板             |
| `focus_next`    | 聚焦下一个面板             |
| `quit`          | 退出应用                   |
| `log_out`       | 退出此账号的登录           |

> 开启 `ui.confirm_quit` 后，每个退出绑定都会先询问：`y` 或 `enter` 退出，`n`、`esc` 或 `q` 取消，再按一次带修饰键的退出绑定（`ctrl+c`、`ctrl+q`）则直接退出。

<a id="navigation--scrolling---contexts-folders-chatlist-chat-context_menu-delete_submenu-search"></a>
### 导航与滚动，上下文 `folders`、`chatlist`、`chat`、`context_menu`、`delete_submenu`、`search`

| 操作               | 说明                                 |
| ------------------ | ------------------------------------ |
| `up`               | 选择上移 / 向上滚动                  |
| `down`             | 选择下移 / 向下滚动                  |
| `go_top`           | 跳到顶部（第一个 / 最旧的）          |
| `go_bottom`        | 跳到底部（最后一个 / 最新的）        |
| `scroll_half_down` | 向下滚动半页                         |
| `scroll_half_up`   | 向上滚动半页                         |
| `cursor_down`      | 把消息光标移到下一个（较新的）气泡   |
| `cursor_up`        | 把消息光标移到上一个（较旧的）气泡   |
| `confirm`          | 确认 / 打开选中的项                  |

<a id="file-picker---context-filepicker"></a>
### 文件选择器，上下文 `filepicker`

| 操作      | 说明                              |
| --------- | --------------------------------- |
| `up`      | 选择上移                          |
| `down`    | 选择下移                          |
| `confirm` | 选择高亮的文件                    |
| `cancel`  | 关闭文件选择器                    |

> 按键名使用终端的叫法：字母和数字照原样写（`r`、`G`、`2`），修饰键写作 `ctrl+d` 这样的形式，具名按键有 `enter`、`esc`、`space`、`up`、`down`、`left`、`right`。

> **键盘布局：** 字母绑定在俄文（ЙЦУКЕН）布局下也会在**同一个物理按键**上生效：无论该键输入的是 `r` 还是 `к`，`r`/Reply 都能用。绑定仍然用拉丁字母书写，无需重复。（目前只映射了俄文布局。）
